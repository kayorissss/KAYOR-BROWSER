# KAYOR BROWSER — минималистичный красивый браузер

> Чёрный / тёмно-серый / белый / серый + эффект **жидкого / матового стекла** как на iPhone + акцент **красный**. Без рекламы. Только для себя.

Живой превью после `npm run dev` → `https://5173-....e2b.app` (Vite на `0.0.0.0`, `allowedHosts: true`).

![KAYOR](public/favicon.svg)

## ✨ Что внутри (по твоему списку)

### 1. Вкладки и навигация
- Создание/закрытие/дублирование/закрепление (pin), перетаскивание drag&drop
- Спящие вкладки, восстановление `Ctrl+Shift+T`, предпросмотр по hover (иконка)
- Вертикальные ↔ горизонтальные вкладки, поиск по вкладкам (когда 50+)
- Split view — два сайта рядом, рабочие пространства «Личное / Работа / Учёба»

### 2. Закладки
- Панель под омнибоксом, папки с цветом, перетаскивание, Speed Dial на новой вкладке, закрепление, импорт/экспорт HTML, облачная синхронизация при входе

### 3. Адресная строка (Omnibox)
- Умный поиск из истории/закладок, выбор поисковика Яндекс / Google / DDG / Bing
- Быстрые команды: `/translate привет` → перевод, `/calc 256*1024` → 262144, `100 usd to rub`
- Замок 🔒 / ⚠️, QR-код, копирование чистой ссылки без UTM

### 4. Загрузки
- Боковая панель + нижний бар с прогрессом, пауза/возобновление, категории, «показать в папке», настройка пути `~/Загрузки/KAYOR`, «спрашивать каждый раз», автоудаление, уведомления

### 5. Аккаунты
- Вход Google OAuth / Яндекс ID (мок — в один клик, аватар, синхронизация), гостевой, мультипрофили

### 6. Безопасность
- Встроенный AdBlock (EasyList) + анти-трекер, блокировка pop-up, инкогнито, менеджер паролей, очистка за период, HTTPS-принуждение, индикатор утечек, DNT, WebRTC toggle, защита от фишинга

### 7. Дизайн
- Тёмная (чёрный #0a0a0f) / Светлая / Стекло, акцент красный `#ff253a` (меняй в настройках), `backdrop-filter: blur(24px) saturate(180%)`, обои на новой вкладке (градиенты + своё фото/Unsplash), анимации, компактный/просторный, скругления 8–28px, HiDPI/Retina, тачскрин

### 8. Настройки
- Основные, внешний вид, приватность, загрузки, языки, система, расширения, о браузере, горячие клавиши (таблица + кастомизация)

### 9. Переводчик
- Автоопределение «Страница на английском, перевести?», перевод всей страницы, выделенного (правый клик), всплывающее окно, выбор языка, API LibreTranslate / MyMemory (бесплатно, можно подключить DeepL)

### 10. Расширения
- Поддержка Chrome CRX (в Electron-сборке через Blink), управление вкл/выкл, встроенные AdBlock/Dark Reader/переводчик

### 11-13. История / Контекстное меню / DevTools
- История с группами «Сегодня/Вчера», поиск, удаление, недавно закрытые, контекстное меню (новая вкладка/инкогнито/копировать/перевести/код элемента), DevTools инспектор

### 14. Фишки

### 15. Установщик
- Красивый анимированный (NSIS + Inno Setup скрипты в корне), мастер первого запуска, тихая установка, деинсталлятор с опросом, портативная версия с флешки

## 🚀 Запуск

```bash
npm install
npm run dev      # http://localhost:5173  (превью на 0.0.0.0:5173)
npm run build    # dist/
npm run preview
```

## 🖥️ Нативная сборка (Electron)

```bash
# dev с Electron (нужен electron + concurrently + wait-on)
npx electron electron-main.cjs
# build — Vite + electron-builder
npm run electron:build
```

Движок — Blink (Chromium). В веб-демо внешние сайты в iframe могут блокироваться `X-Frame-Options` → показывается fallback «Открыть отдельно». В Electron это решается нативным `<webview>` без ограничений.

## 📦 Установщик Windows

- `installer.nsi` — NSIS скрипт (OutFile `kayor-installer-1.0.0.exe`, выбор папки, ярлык)
- `installer.iss` — Inno Setup (см. файл)
- Тихая установка: `kayor-installer.exe /S`
- Портатив: распакуй `dist` на флешку, запускай `KAYOR.exe --portable`

Мастер первого запуска — на новой вкладке: выбор темы, поисковика, импорт закладок, приветствие «Добро пожаловать, Исследователь» (имя редактируется).

## 🎨 Темы

- Переключение в шапке/настройках: Светлая / Тёмная / Стекло
- Акцент: красный (по умолчанию), синий/зелёный/фиолетовый/пипетка
- Стекло: `glassStrength` 0–40px, `backdrop-filter: blur()`
- Обои: 6 градиентов + загрузка своего фото
- Скругления 8–28px, компактный режим

## 🔍 Переводчик

Работает без ключа через `https://api.mymemory.translated.net`. Для продакшена подключи `LibreTranslate` self-hosted или DeepL API — поменяй URL в `handleTranslate()`.

## 🛡️ Блокировщик

Переключатель в омнибоксе `AdBlock ON/OFF` (состояние в `adblock`). В продакшене подключи списки EasyList / uBlock Origin и фильтрацию в Electron `webRequest`.

## 📁 Структура

```
src/
  App.tsx          # весь браузер (табы, омнибокс, боковая, новая вкладка, настройки)
  styles/index.css # glass, tailwind
  main.tsx
public/favicon.svg # логотип — замени своим (скинь в папку)
electron-main.cjs  # Electron main
preload.cjs
installer.nsi / installer.iss
```

## 🔧 Кастомизация логотипа

Замени `public/favicon.svg` своим SVG/PNG (квадрат 512×512). В коде логотип — блок `KAYOR` с градиентом `accent`. Иконки вкладок и Speed Dial берут первую букву.

## ⌨️ Горячие клавиши

`Ctrl+T` новая, `Ctrl+W` закрыть, `Ctrl+Shift+T` восстановить, `Ctrl+L` адрес, `Ctrl+K` команды, `Esc` закрыть модалки.
